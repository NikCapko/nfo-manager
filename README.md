# NFO Editor

Простой, однофайловый десктопный редактор для редактирования файлов `.nfo`, связанных с видеоконтентом.
Этот редактор позволяет пользователям управлять метаданными своих медиафайлов (таких как `.mp4`),
создавая и редактируя соответствующий файл `.nfo`.

## 💾 Особенности

NFO Editor предоставляет комплексный интерфейс для управления метаданными медиа, включая:

*   **Редактирование метаданных:** Выделенные поля для основной информации о фильме, такой как Название, Оригинальное название, Год, Сюжет и Название файла.
*   **Управление категориями:** Инструменты для управления и сохранения структурированных данных, таких как Студии, Жанры и Теги.
*   **Управление актёрами:** Выделенный раздел для перечисления актёров вместе с их ролями.
*   **Привязка файлов:** Автоматически связывает файл `.nfo` с соответствующим медиафайлом (`.mp4`).
*   **Просмотр файлов:** Позволяет просматривать папки с видеофайлами (`.mp4`), с возможностью включения подпапок.
*   **Предпросмотр в реальном времени:** Предоставляет предварительный просмотр видео и базовые элементы управления воспроизведением (воспроизведение/пауза/перемотка).
*   **Хранение истории:** Сохраняет ранее использованные студии, жанры, теги и актёров в локальном файле конфигурации (`~/.config/nfo_editor/history.json`) для ускорения ввода данных.
*   **Сохранение структуры:** Гарантирует, что обновляются только конкретные поля при сохранении, сохраняя структуру XML-документа.

## 🛠 Зависимости

*   `PyQt6`: Фреймворк, используемый для графического интерфейса.

Для установки требуемой зависимости выполните:
```bash
pip install PyQt6
```

## 🚀 Как запустить

Приложение разработано для запуска из командной строки, передавая путь к целевому файлу или папке в качестве аргумента.

### 1. Запуск папки

Если у вас есть папка с видеофайлами, запустите приложение, указав путь к этой папке. Оно отсканирует все файлы `.mp4` в папке и ее подпапках (в зависимости от настроек).

```bash
python3 nfo_manager.py /путь/к/папке/видео
```

### 2. Открытие конкретного файла .nfo

Если у вас уже есть файл `.nfo`, запустите приложение с путем к этому файлу. Редактор загрузит существующие метаданные и запросит соответствующий файл `.mp4`.

```bash
python3 nfo_manager.py /путь/к/медиа/file.nfo
```

### 3. Открытие конкретного файла .mp4

Если у вас есть только видеофайл, запустите приложение с путем к `.mp4`. Редактор создаст пустой документ `.nfo` и свяжет его с видеофайлом.

```bash
python3 nfo_manager.py /путь/к/медиа/file.mp4
```

## 🧭 Краткое руководство по запуску

1.  **Запуск приложения:** Выполните соответствующую команду.
2.  **Навигация:** В левой панели отобразятся все найденные файлы `.mp4`. Выберите целевой файл.
3.  **Редактирование метаданных:** Введите данные в центральной панели (Название, Сюжет и т.д.).
4.  **Управление категориями:** Используйте кнопки «Добавить» рядом со Студиями, Тегами и т.д., чтобы добавлять элементы, используя функцию истории.
5.  **Сохранение:** Нажмите кнопку «Сохранить», чтобы записать изменения в файл `.nfo`.
